# Image provenance

## videos/ho-chi-minh-archive.mp4

Edited 24-second loop created for this exhibition from four public-domain historical photographs listed in `public/videos/README.md`. It is a moving presentation of still images, not original historical film footage. The original Commons links and licensing notes for each photograph remain in this manifest.

## archive/reading-table.webp

Generated with the built-in image generation tool. Contemporary illustrative still life, explicitly labeled in the UI. No historical authenticity is claimed.

Final prompt:

> Create a photographic still life for a Vietnamese academic digital museum. Landscape 3:2 composition. Close overhead view of an open aged blank notebook, loose cream paper, closed worn linen books and a black fountain pen on a dark wood archive reading table. Soft daylight from left, restrained warm monochrome, deep brown black shadows, beautiful authentic paper textures, quiet scholarly atmosphere. No people, no writing, no letters, no historical claims, no symbols, no logos. This is a contemporary illustrative placeholder, not a historical document. Full bleed photograph, no border.

The generated original remains in the generation tool's output directory. This project uses a 1400px WebP derivative.

## Documentary redesign photography

### hero/france-1946.webp

Source: https://commons.wikimedia.org/wiki/File:Ho_Chi_Minh_with_Vietnamese_expats_in_France,_1946.jpg
Unknown author. Commons marks PD-Vietnam and PD-1996. Description: Hồ Chí Minh in conversation with Vietnamese expatriates in France, 1946. Downloaded original is retained as `hero/france-1946.jpg`; the website uses a resized WebP copy and CSS grayscale.

### archive/meeting-1946.webp

Source: https://commons.wikimedia.org/wiki/File:1946_Ho_Chi_Minh_Leclerc_Sainteny_2.png
Photographer attribution: Service Cinématographique des Armées. Scanned by Loc Vu-Quoc from Philippe Devillers, _Histoire du Viêt-Nam de 1940 à 1952_ (1952). Commons marks PD-France and PD-Vietnam. Description date: 18 March 1946. The original PNG is retained. The website uses a WebP copy and CSS grayscale.

Timeline use is explicitly labeled as reference imagery, with the photograph’s actual date and source retained. These photographs are not presented as depicting each placeholder timeline year.
